# evals

Local skill evals against throwaway fixture repositories.

Evals live outside distributable skill directories because consumers install a skill, not its test infrastructure. See [validate by observation](../docs/best-practices/validate-by-observation.md).

- [Agent guide](AGENTS.md): commands, paid-run approval, and development rules.
- [Verification](docs/verification.md): runtime, results, assertion tiers, coverage limits, and adding a case.
