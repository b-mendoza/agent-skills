# External References For Recency Guard

Checked on 2026-06-12. These are external resources that perform, enable, or explain work comparable to Recency Guard's current-fact validation, source evaluation, claim review, and cautious final-answer wording.

| Resource | What It Is | Why It Is Relevant |
| --- | --- | --- |
| [OpenAI API Web Search](https://platform.openai.com/docs/guides/tools-web-search) | Hosted web-search tooling for retrieving current information during model responses. | Recency Guard depends on current-source verification for time-sensitive claims. This is a comparable retrieval capability for the `recency-checker` portion of the workflow, though Recency Guard adds orchestration, repair caps, and final-answer wording rules. |
| [Deep research in ChatGPT](https://help.openai.com/en/articles/10500283-deep-research-in-chatgpt) | A multi-step online research workflow that can use the public web, selected sites, uploaded files, and connected apps, then returns a structured report with source links. | Comparable at the research-orchestration level: it emphasizes source control, progress visibility, and citations. Recency Guard is narrower and answer-validation oriented rather than a broad research-report tool. |
| [Tavily Search Engine docs](https://docs.tavily.com/documentation/about) | A search engine and extraction API optimized for LLM agents and RAG workflows. | Relevant as an external tool category for the kind of web-heavy verification Recency Guard delegates to `recency-checker`, especially current web retrieval and source extraction for agent workflows. |
| [Perplexity Search API](https://docs.perplexity.ai/docs/search/quickstart) | A real-time web-search API returning ranked structured results with fields such as title, URL, snippet, date, and last-updated metadata. | Relevant to Recency Guard's need to inspect current, date-sensitive evidence and preserve source metadata when deciding whether a claim needs replacement, date-stamping, qualification, or removal. |
| [Perplexity Sonar API](https://docs.perplexity.ai/docs/sonar/quickstart) | A web-grounded answer API with built-in search capabilities and cited generated responses. | Comparable to the final-answer side of Recency Guard: both aim to ground generated answers in web evidence. Recency Guard differs by separating recency auditing, claim stress-testing, and evidence integration into explicit phases. |
| [Schema.org `ClaimReview`](https://schema.org/ClaimReview) | A structured-data type for fact-checking reviews of claims, including the reviewed claim and review body. | Relevant because Recency Guard is organized around claim-level review, not generic source summaries. `ClaimReview` shows an external structured vocabulary for claim-centered fact checking. |
| [Google Search Central: Fact Check (`ClaimReview`) structured data](https://developers.google.com/search/docs/appearance/structured-data/factcheck) | Implementation guidance for fact-check pages that use `ClaimReview`; Google notes Search support is being phased out while Fact Check Explorer support remains. | Relevant as a practical external ecosystem for claim-level fact-check publication and validation. It also shows why current documentation matters: feature support can change over time. |
| [SIFT: The Four Moves](https://hapgood.us/2019/06/19/sift-the-four-moves/) | Mike Caulfield's web-literacy method: stop, investigate the source, find better coverage, and trace claims to original context. | Directly aligned with Recency Guard's evidence policy: prefer better sources, investigate authority, and trace claims instead of accepting first-pass web snippets. |
| [CRAAP Test, Meriam Library, California State University Chico](https://library.csuchico.edu/sites/default/files/craap-test.pdf) | A source-evaluation checklist for currency, relevance, authority, accuracy, and purpose. | Relevant to Recency Guard's confidence labels and source-tier judgments, especially the skill's emphasis on freshness, source authority, evidence support, and whether current information is required. |
| [Purdue OWL: Logical Fallacies](https://owl.purdue.edu/owl/general_writing/academic_writing/logic_in_argumentative_writing/fallacies.html) | A writing and reasoning guide describing common failures such as hasty generalization, false cause, circular argument, and either/or reasoning. | Relevant to `claim-verifier`, which tests decision-shaping claims for overstatement, causal leaps, narrow-to-broad generalization, single-source anchoring, survivorship bias, and opinion framed as fact. |
| [Scribbr: Correlation vs. Causation](https://www.scribbr.com/methodology/correlation-vs-causation/) | A methodology explainer distinguishing statistical association from causal claims and describing confounders and directionality problems. | Relevant to Recency Guard's claim stress-test when a draft turns correlation, benchmark results, or observational evidence into causal wording stronger than the evidence supports. |
| [Duke University Libraries: ChatGPT and Fake Citations](https://blogs.library.duke.edu/blog/2023/03/09/chatgpt-and-fake-citations/) | A library note warning that AI-generated citations can appear legitimate while not corresponding to real sources. | Relevant to Recency Guard's trust model and final-answer restraint: citations and source claims need verification, and unsupported evidence should be removed or explicitly qualified. |

## Notes
